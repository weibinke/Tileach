# Tileach
Tileach is a Python library for Neural Network Programs. It provides a simple and intuitive interface for building and training Neural Networks.
## Install method
To install Tileach, simply run the following command:

```Terminal
pip install tileach --password <Tl_n>
```

or

```Terminal
git clone https://github.com/Tileach/Tileach.git
cd Tileach
python setup.py install
```

or

```Terminal
pip install git+https://github.com/Tileach/Tileach.git
```

or

```Terminal
pip3 install tileach --password <Tl_n>
```

## password:
The password is: `<Tl_n>`
## Usage
To use Tileach, simply import the `Tileach` module and create a new neural network model by creating a `Tl` object:

```python
import Tileach as tl

# Create a new neural network model
model = tl.Tl((tl.TlNeurons(input("Enter the msg:"))
```
